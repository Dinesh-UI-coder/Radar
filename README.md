# Radar
Android application for real-time flight tracking

RadarSystem is an advanced Android application for real-time flight tracking, built with MapLibre SDK and Kotlin.

To run the project correctly, you need to configure the following API Keys within the `MainActivity.kt` file (or in the appropriate configuration file):

Logostream Company logos and flags | [Get Key](https://logostream.dev/) |
MapTiler Vector maps and styles | [Get Key](https://www.maptiler.com/cloud/) |
OpenSky Live air traffic data | [Register](https://opensky-network.org/) |
AeroDataBox Flight and airport details | [Get on RapidAPI](https://rapidapi.com/aedabt/api/aerodatabox/) |

Key features

Live Tracking: View thousands of aircraft on the map with continuous updates.
Flight Details Click on an aircraft to receive information about the model, route (departure/arrival), and flight status.
Visual Identity Original airline logos and national flags thanks to integration with Logostream.
Aircraft Info Real photos of specific aircraft through Planespotters integration.
